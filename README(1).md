# 데이터로 감염병 유행을 추적하라! 🦠

고등학교 1학년 통합과학2 **「과학과 미래사회」** 단원에서 사용할 수 있는
Streamlit 기반 감염병 데이터 탐구 웹앱입니다.

## 핵심 수업 목표

- 실제 감염병 데이터를 이용해 시간에 따른 변화와 패턴을 분석한다.
- 빅데이터가 감염병 추적과 의사결정에 어떻게 활용되는지 생각한다.
- **데이터에서 확인되는 사실**과 **원인에 대한 해석**을 구분한다.
- 상관관계와 인과관계를 구분하고, 추가로 필요한 데이터를 제안한다.

## 1. 로컬 실행

Python 3.10 이상을 권장합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 열리면 사이드바에 Claude API 키를 입력하고 CSV를 업로드합니다.

---

## 2. Streamlit Community Cloud 배포

1. GitHub에 새 저장소를 만듭니다.
2. 이 폴더의 파일을 모두 업로드합니다.
3. Streamlit Community Cloud에서 `app.py`를 지정하여 배포합니다.
4. **학생용 앱에서는 API 키를 코드에 넣지 마세요.**

### 권장: Streamlit Secrets에 교사용 API 키 저장

Streamlit Community Cloud 앱 설정의 **Secrets**에 아래 내용을 넣습니다.

```toml
ANTHROPIC_API_KEY = "발급받은_실제_API_키"
```

앱은 Secrets에 키가 있으면 자동으로 사용합니다.
Secrets가 없을 때만 사이드바에서 API 키를 입력받습니다.

> 절대로 실제 API 키를 `app.py`, `README.md`, GitHub 저장소에 직접 기록하지 마세요.

---

## 3. 모델명

기본 모델명은 연수 자료에 맞추어 다음과 같이 설정되어 있습니다.

```text
claude-sonnet-4-6
```

사용 중인 Anthropic 계정에서 해당 모델을 사용할 수 없다는 오류가 나오면
사이드바의 **Claude 모델명**을 현재 계정에서 사용 가능한 모델명으로 수정하세요.

---

## 4. 수업용 데이터

`sample_data/백일해_2015-2024_전국발생자수.csv`를 바로 사용할 수 있습니다.

열 구조:

```csv
연도,백일해_발생자수_명
2015,205
...
2024,48048
```

앱은 UTF-8, UTF-8-SIG, CP949, EUC-KR CSV를 순서대로 읽도록 되어 있습니다.

---

## 5. 학생 활동 흐름

1. CSV 업로드
2. 데이터 미리보기와 기초 통계 확인
3. 기본 그래프 확인
4. **AI 분석 전에 '나의 예상' 작성**
5. 데이터에 대한 탐구 질문 입력
6. AI 분석 확인
7. **'나의 최종 해석' 작성**
8. 탐구 기록 TXT 저장

AI 응답은 다음 구조로 제한됩니다.

1. 데이터에서 직접 확인되는 사실
2. 추천 시각화
3. 발견할 수 있는 패턴
4. 가능한 해석 또는 가설
5. 이 데이터의 한계
6. 다음 탐구를 위해 필요한 데이터와 탐구 질문

- 로그 척도는 어떤 장점과 한계를 가지는가?
- 시각화 방식이 데이터 해석에 영향을 줄 수 있는가?

## 7. 오류 해결

### API 인증 실패
API 키를 다시 확인하세요.

### 모델 관련 Bad Request
사이드바의 모델명이 현재 Anthropic 계정에서 사용 가능한지 확인하세요.

### CSV를 읽지 못함
- CSV 확장자인지 확인
- 첫 행에 열 이름이 있는지 확인
- UTF-8 또는 CP949로 저장해 다시 시도

### 한글이 그래프에서 깨짐
Streamlit Cloud 환경의 기본 폰트에 따라 한글 글꼴 경고가 나타날 수 있습니다.
데이터 분석에는 영향이 없지만, 필요한 경우 별도 한글 폰트 설치 설정을 추가할 수 있습니다.

---

## 8. 보안 주의

- API 키를 GitHub에 올리지 않습니다.
- 학생에게 교사용 API 키를 직접 알려주지 않습니다.
- Anthropic 콘솔에서 사용량을 주기적으로 확인합니다.
- 수업용으로 배포할 경우 비용 한도를 설정하는 것을 권장합니다.
- 학생 개인정보가 포함된 CSV는 업로드하지 않습니다.

---

## 9. 교육적 설계 원칙

이 앱은 AI가 원인을 단정하도록 설계하지 않았습니다.
CSV에서 확인할 수 있는 것은 '사실'로, CSV 밖의 원인 설명은 '가설'로 구분하게 합니다.

핵심 문장:

> 데이터가 보여 주는 사실과 그 원인에 대한 해석은 구분해야 합니다.
